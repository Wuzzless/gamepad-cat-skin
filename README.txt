CAT GAMEPAD VIEWER SKIN

Files:
- cat-skin.css
- cat-skin.jpg

IMPORTANT:
GamePad Viewer cannot load these from your PC directly.
Upload BOTH files to the same public web folder (GitHub Pages works).

Then:
1. Select Xbox One in GamePad Viewer.
2. Use the public URL ending in /cat-skin.css in "Edit CSS URL".
3. Keep cat-skin.jpg in the exact same folder as cat-skin.css.
4. Generate/save the GamePad Viewer URL.

The controller buttons remain handled by GamePad Viewer; the CSS adds your exact cat artwork.
